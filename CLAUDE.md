# Project notes

This repo (`5urfbutler/5urfbutler.github.io`) is the public support / privacy
website for **TreCastr**, a hyperlocal information viewer app for iOS, iPadOS
and macOS. It is a single static `index.html`.

The TreCastr application source lives in a separate repo:
`5urfbutler/HomeView` (private, C++). That is where app issues / "cases" are
tracked.

## Working preferences

- **Issue tracking: GitHub Issues only.** Do not use Jira. When the user
  refers to a "case #N", treat it as a GitHub issue (typically in the
  `5urfbutler/HomeView` repo, where the app's issues live).
